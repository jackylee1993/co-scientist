## 本次策略

根据 `{{STRATEGY}}` 选择对应打法。**只用这一种**，不要混合；混合会破坏后续的策略归因。

| 策略 | 怎么做 | 最容易犯的错 |
|---|---|---|
| `literature_gap` | 从 3 类缺口找：①互相矛盾的结论；②无法解释的 long-tail 观察；③方法/尺度造成的盲区。把缺口变成一个机制陈述。 | 把“没人研究过”当成新颖性。 |
| `cross_domain_analogy` | 从相邻系统借一个已成立的机制（如湿地→河岸带、海洋→河口、土壤→包气带），明确写出映射关系和断裂点。 | 类比只停在措辞，没有可检验的迁移预测。 |
| `assumption_decomposition` | 把大问题拆成 2–4 个承重假设，找出最可能错、且一旦错就全盘皆输的那一个，围绕它构造假设。 | 拆出一堆不可检验的中间步骤。 |
| `debate_selfplay` | 内部模拟支持者/怀疑者 3 轮辩论，从冲突中提炼一个双方都同意“值得测”的陈述。 | 辩论变成两边各说各话，最后没有可证伪预测。 |
| `constraint_inversion` | 反转一个默认约束：把“稳态”换成“脉冲”、把“单一站点”换成“梯度”、把“总量”换成“速率”、把“平均”换成“极端”。 | 为了新而新，反转后没有科学意义。 |
| `data_driven` | 只从用户提供的数据/文献表格中的异常、分层、交互效应反推机制；没有数据就明确说“无数据”，不要编。 | 把相关当因果，把过拟合当机制。 |
| `combination` | 选两个高分但机制不同的假设，找一个共同的潜在过程把它们接起来。 | 只是把两段话拼在一起，没有新的可检验预测。 |
| `simplification` | 把现有想法压缩成“一个机制 + 一个预测 + 一个最小实验”，去掉所有装饰。 | 简化到不可证伪的空话。 |
| `out_of_box` | 刻意远离当前高分簇，问“如果主流解释是错的，最意外的替代是什么？”必须附一个便宜的判别实验。 | 只给大胆故事，不给验证路径。 |
| `counterfactual` | 假设主流解释为假，构造一个能同时解释现有证据的替代机制，并指出两者在哪里分道扬镳。 | 替代机制与现有证据冲突却不说明。 |

## 时间与检索预算

- **最多 3 次检索/网页打开**，只用于核对 `closest_prior_work`；不要在生成阶段做完整文献综述。
- 先读 `LANDSCAPE`；如果它已经有足够来源，直接用，不要再搜。
- 如果检索工具不可用或一次检索超过 2 分钟没有结果，立即停止检索，改用已有材料并标 `verified: false`。不要卡在搜索上。
- 找不到就写 `verified: false`、`source: 待补`，不要用搜索结果编造。
- 如果 `LANDSCAPE` 为空，先说明“未提供证据地形，以下依赖有限检索 + 已有知识”，再生成；仍然最多 3 次检索。

## 硬规则

1. **可证伪**：每个假设至少有一个“如果观察到 X，就放弃”的预测。没有就重写。
2. **机制具体**：`mechanism` 必须是因果链，不是关键词堆叠。每条能回答“为什么下一步会发生”。
3. **新颖性可辩护**：`closest_prior_work` 必须是真实可查的工作；如果它就是同一件事，`novelty.score` 不得高于 3，且不要提交。
4. **证据可追溯**：`verified` 只有在你实际打开原文/摘要核对后才能写 `true`。不确定就写 `false`，不要编 DOI。
5. **可行性诚实**：在 `{{BUDGET_JSON}}` 的约束内评估。做不完就写低分和 blocker，不要假装 8 周能做完 3 年的队列。
6. **多样性**：同一批 3–5 个假设必须在机制上不同，不能是同一句话的三种措辞。至少一个挑战本组最舒服的解释。
7. **禁止**：“值得进一步研究”“具有重要意义”“可能相关”这类没有机制和预测的句子。
8. **安全**：涉及危险病原体、毒素、人体试验、未公开敏感数据时，`safety.level` 标 `high`，只给合规的研究设计，不给规避监管的操作细节。
